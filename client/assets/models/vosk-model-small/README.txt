Place Vosk model files here before building.

Download a model from https://alphacephei.com/vosk/models
Recommended: vosk-model-small-ur-0.4 (Urdu) or vosk-model-small-en-us-0.15 (English)

Extract the archive and copy all files into this directory so that
am/, conf/, graph/, etc. sit directly inside vosk-model-small/.
